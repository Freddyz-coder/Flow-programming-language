Example 1:
Input:
~~~ Block scoping demo ~~~
~~~ Variables from an outer scope can be changed inside a block... ~~~
>> total = 0;
again 5 {
    total = total + 1;
}
"total:" << show: Add.space << total << show;

~~ ...but a variable CREATED inside a block only lives in that block. ~~
>> i = 0;
>> sum = 0;
aslong i < 5 {
    >> doubled = i * 2;  ~~ 'doubled' only exists for this pass ~~
    sum = sum + doubled;
    i = i + 1;
}
"sum of doubles:" << show: Add.space << sum << show;


Output:
total: 5
sum of doubles: 20

Example 6:
Input:
~~ Binary Search Tree in Flow ~~
~~ Demonstrates recursion, maps, arrays, loops, and immutability ~~

~~ Sentinel for an empty tree ~~
>> empty = "empty";

~~ Insert a value into a BST (returns a new tree) ~~
put insert(t, v) {
    check t == empty then {
        take map { val: v, left: empty, right: empty };
    } else {
        check v < t.val then {
            take map { val: t.val, left: insert(t.left, v), right: t.right };
        } else {
            take map { val: t.val, left: t.left, right: insert(t.right, v) };
        }
    }
}

~~ In‑order traversal: prints values in sorted order ~~
put inorder(t) {
    check t != empty then {
        inorder(t.left);
        t.val << show: Add.space;
        inorder(t.right);
    }
}

~~ ---- Main program ---- ~~
>> values = box [5, 3, 7, 2, 4, 6, 8];   ~~ our unsorted numbers
>> tree = empty;
>> i = 0;

~~ Build the tree by inserting each element ~~
aslong i < 7 {
    tree = insert(tree, values index i);
    i = i + 1;
}

~~ Print the sorted tree ~~
"Sorted values: " << show: Add.space;
inorder(tree);
"" << show;   ~~ final newline



Output:
Sorted values:  2 3 4 5 6 7 8
